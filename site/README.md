# site/ — landing + politika privatnosti

Statične stranice za GitHub Pages. Play Console zahteva javan URL politike privatnosti.

## Objava (jednom)
1. Novi javni repo, npr. `upecaj-site`.
2. Kopiraj sadržaj ovog foldera u root repoa, push na `main`.
3. Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/root`.
4. URL: `https://<github-user>.github.io/upecaj-site/` i `.../privacy.html`.

## Pre objave zameni
- ~~`KONTAKT_MAIL`~~ → ✅ upecaj.rs@gmail.com upisan
- `PLAY_URL` → `https://play.google.com/store/apps/details?id=rs.upecaj.app` (u `index.html`)
- screenshot-ove u `site/img/` + ubaci ih u `index.html`

Datum na vrhu `privacy.html` menjaj svaki put kad se politika promeni (npr. kad se doda crash reporting).
